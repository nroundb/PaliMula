Evampi kho, bhikkhave, bhikkhu kāye kāyānupassī viharati.

학습용 직역: {이와 같이|evampi} {참으로|kho}, {비구들이여|bhikkhave}, {비구는|bhikkhu} {몸에서|kāye} {몸을 관찰하며|kāyānupassī} {머문다|viharati}.

evampi ([evaṁ + api])

* evaṁ (ind. adv.) — 이와 같이.
* api (ind. emph.) — 도, 역시.

kho (ind. emph.) — 참으로, 확실히.

bhikkhave (bhikkhu. m.pl.voc.) — 비구들이여.

bhikkhu (bhikkhu. m.sg.nom.) — 비구는.

kāye (kāya. m.sg.loc.) — 몸에서.

kāyānupassī (kāya + anupassī. adj. comp. m.sg.nom.) — 몸을 관찰하며.

* kāya (m.) — 몸.
* anupassī (adj.) — 관찰하는.

viharati (vi + hara + ti. √har. 3rd.sg.pres.) — 머문다.

**[문장 구조 및 특징]**
명상 지침의 한 섹션을 마무리하는 정형구로, 첫 문장(3번째 문장)의 질문에 대한 답변 형식으로 구조적 완결성을 부여한다.
